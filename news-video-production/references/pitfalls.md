# 常见问题与处理

## 时长/帧数

| 现象 | 原因 | 处理 |
|---|---|---|
| 成片 12.1 秒、切点漂移 | 单镜不是 90 帧，或转场吃了帧 | 固定 `durationInFrames=N*90`；转场在镜内做，不跨 Sequence |
| 总时长和脚本对不上 | 用了脚本里的 5/8/9 秒 | 忽略脚本时长，只按镜头数 ×3 秒 |
| 想拉长到 15 秒 | 单镜被拉长 | 只能加镜头，不能改单镜 |

## Remotion/渲染

| 现象 | 原因 | 处理 |
|---|---|---|
| Chromium 启动失败 | 目标环境缺浏览器/依赖 | 运行 `npx remotion browser ensure`；确认 Chromium 可执行 |
| 渲染中途崩溃/单帧泛白 | 并发过高、内存峰值 | `--concurrency=1`；分镜渲染后再合并 |
| 中文字体变成方框 | 目标环境字体缺失 | 字体文件放 `public/fonts/`，CSS 显式 `fontFamily` |
| 导出没有音频 | Remotion Audio 未挂载/未渲染 | 检查 `<Audio>` 在 Composition 内；ffprobe 确认音频流 |
| 输出不是 1080×1920 | Composition 参数写错 | 固定 `width=1080,height=1920,fps=30` |
| 渲染出来发灰 | 色彩空间/编码 | `--pixel-format=yuv420p`；最终 FFmpeg 再封装 |

## 素材

| 现象 | 原因 | 处理 |
|---|---|---|
| 实拍画面抽动 | 源是 24/25fps，时间线 30fps | 先 `minterpolate` 到 30fps，再进 Remotion |
| 插帧鬼影/撕裂 | 快速运动、遮挡 | 降低插帧强度或换素材；不要硬插 |
| 同一素材反复出现 | 素材不够 | 补新素材/信息卡/图表，不重复角度 |
| 画面角落有台标/水印 | 素材自带角标 | 裁掉或换素材；不要用带角标的图 |
| 素材被缩进安全区 | 误把素材当文字 | 素材满幅；只有文字受安全区限制 |

## 版式

| 现象 | 原因 | 处理 |
|---|---|---|
| 标题居中/每镜换标题 | 沿用旧模板 | 主标题和下方标题都用脚本标题，左对齐、全片固定 |
| 字幕底板只在部分镜头出现 | 被当成“字幕”而非常驻层 | 底板放固定层，全片常驻 |
| 卡片有描边 | 旧样式残留 | 卡片去描边；只保留圆角和底色 |
| 时间轴在卡片外 | 旧版式 | 时间轴移入卡片，标题下方 |
| 片尾还有账号/栏目 | 模板残留 | 片尾卡只留结论/提示，删左下角账号/栏目 |
| 标题溢出/压字 | 字号过大 | 按 64–95px 调；长片主标题 95、下方 53、正文 37 上限 |

## 声音

| 现象 | 原因 | 处理 |
|---|---|---|
| BGM 盖住口播 | 增益过高 | BGM 0.20；先降 BGM，不降口播 |
| 每 3 秒一个 whoosh | 逐镜加音效 | 只留段落起点/数据卡/结尾，约 10 处/100 秒 |
| 音效像电子合成 | 程序生成 | 换免版税实录音效 |
| BGM 断成两段 | 截取/循环错误 | 用连续片段；不做淡入淡出；不循环拼接 |

## 交付

| 现象 | 原因 | 处理 |
|---|---|---|
| 飞书上传报 `1061043` | 单文件 >20MB | 打 zip；或分卷/换通道 |
| 单元格附件报 `all file has no relation` | 跨租户 token 直写 | 走目标平台的文件/素材上传通道 |
| mp4 直传返回空地址 | 平台 mp4 通道限制 | 改 zip；或走视频消息通道 |
| 预览只有 2Mbps | 平台转码固定低码率 | 只当预览；母版用 Remotion + FFmpeg 12Mbps |
| B 站下载 412 | 平台风控 | 换 BV/换源；不要反复重试同一链接 |
| 本地旧版被覆盖 | 沿用“只留最新版”旧规则 | 保留 `versions/` 全部版本，不删旧版 |
