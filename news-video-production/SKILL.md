# 资讯视频制作

## 0. 先读规则

- 任何时长、版式、声音、交付决策，先读 `references/hard-rules.md`；**最新偏好优先于旧模板文档和旧 SOP**。
- 选模板、排版式，读 `references/style-guide.md`。
- 套用/新增包装主题，读 `references/theme-system.md`；模版工程在 `assets/theme-kit/`。
- 搭 Remotion 工程、写合成代码，读 `references/remotion.md`。
- 配乐、音效、混音，读 `references/audio.md`。
- **成片后必须读 `references/self-check.md`，跑完自检才允许发 CDN。**
- 交付、归档、飞书上传，读 `references/delivery.md`。
- 换环境、装依赖、初始化项目，读 `references/install.md`。
- 遇到异常，读 `references/pitfalls.md`。

## 0.1 路径与环境

- `SKILL_DIR` = 本 Skill 根目录（含 `SKILL.md`）。所有脚本用 `"$SKILL_DIR/scripts/..."` 调用，不写死 `/home`、`/Users`、`/runtime` 或盘符。
- 首次在别的环境使用，先运行 `python3 "$SKILL_DIR/scripts/check_env.py"`，确认 Node 18+、FFmpeg、ffprobe、npm/npx 可用。
- 缺 Chromium 时运行 `npx remotion browser ensure`；缺飞书/CDN 时走本地归档、网盘或任意可访问 mp4 链接，不阻塞制作。
- 初始化 Remotion 项目：`bash "$SKILL_DIR/scripts/scaffold_remotion.sh" ./remotion-news-video`；Windows 用 `scripts/scaffold_remotion.ps1`。
- 详细依赖、离线处理、Windows 路径见 `references/install.md`。

## 1. 接任务

从用户输入提取四类信息：

1. **脚本来源**：飞书文档链接 + 脚本名/章节；只读指定段落。
2. **模板**：T01 / T02 / T03 / T04；用户未指定时按内容判断，判断依据见 `style-guide.md`。
3. **特殊要求**：标题行数、是否用截图、背景视频方向、口播/无口播、封面、发布平台、安全区档位。
4. **素材**：用户给的链接或本地文件；其余由助手检索、截图、下载并保存。

关键材料缺失时先列缺口，不猜数字、日期、责任人、事实表述或系统状态。

## 2. 读脚本、定镜头

- 只读指定文档与章节；不改事实、数字、标题。
- 提取：脚本标题、每段正文/重点、画面建议（仅参考）、发布文案、来源。
- 删除“资讯版/镜号 1”等无效段；有效段落数记为 `N`。
- **资讯模板固定 3 秒/镜**；总时长 = 镜头数 × 3 秒。要改总时长只能增删镜头，不能把单镜拉长/缩短。
- 口播/访谈类不套 3 秒规则：按脚本与语音节奏切分，单镜时长按实际语音长度计算。
- 先输出镜头表：段号、素材、正文、重点词、转场、音频节点、对应卡片。

## 3. 选模板

| 编号 | 名称 | 用途 | 关键特征 |
|---|---|---|---|
| **T01** | 深蓝/蓝图资讯版 | 需要证据感、截图、公告、数据支撑 | 深色工程蓝图底；满幅素材/产品页；暖白资讯卡 |
| **T02** | 白卡快讯版 | 信息短、画面强的快讯 | 干净底色；满幅实拍；白卡红字强调 |
| **T03** | 话题视频背景版 | 信息量较大、需要氛围和节奏 | 话题相关视频叠模糊作背景；白卡黄色高亮 |
| **T04** | 红白几何版 | 产业/展会/数据快讯，红白主色＋黄辅色 | 红白渐变底+几何斜切；满幅素材带；白色圆角卡；数据胶囊 |

- 长片（约 30 秒以上或 10 镜以上）不必硬套 T01–T03；用共通版式，背景可选 T03 的话题视频。
- 新样式优先在 `assets/theme-kit/` 里加一个主题文件并在 `theme/registry.ts` 登记，不改通用组件；需要不同结构时用 `ThemeEntry.Film/Cover` 覆盖。
- **所有模板都必须遵守 `hard-rules.md` 的最新版式与安全区**：标题左对齐加粗、字幕/信息卡底板常驻、卡片无描边、时间轴在卡片内、片尾不留账号/栏目。
- T04 的 2026-11-26 旧版卡片贴底（bottom 90px），已不符合现行抖音安全区；新片必须用 `bottom ≥ 300px` 的安全版坐标，见 `style-guide.md`。

## 4. 找素材

- 素材由助手检索、截图、下载并保存；用户给链接也要落地保存。
- **图片与实拍视频片段混用**，不要全片静图。
- 每张素材只出现一次；素材不够时用信息卡、图表或新素材，不重复同一角度。
- 背景/实拍满幅铺开；产品抠图允许放在“产品页”布局中，但必须避开标题与信息卡，不裁掉产品关键部位。
- 实拍视频统一转 **30fps CFR**：用 `setpts` 对齐源帧，**不做运动插帧**；具体命令见 `remotion.md`。
- 硬切为主；图片↔实拍、产品页之间可 4–8 帧交叉淡入，章节/时空跳点才用其他转场，不逐切点堆。
- 记录 `_来源.json`：`purpose`（fact/context）、`sourceUrl`、`license`；产品抠图记录原图 URL 与处理脚本。

## 5. Remotion 合成

- 统一用 Remotion，不再用 PIL/Pillow 逐帧脚本。
- Composition：1080×1920、`fps=30`；资讯模板 `durationInFrames = 镜头数 × 90`（3 秒/镜）；封面冻结帧另计，用 `--no-duration-check` 复核其余规格。
- 主标题只用脚本标题，全片固定，左对齐加粗；每段变化的是资讯卡结论/正文，不是大标题。
- 字幕/信息卡底板常驻；卡片无描边；时间轴放在卡片内；片尾卡片不保留左下角账号与栏目文字。
- **抖音安全区常量**：TP01/T01 标题顶部 ≥ 240px，平台最低约 120px（T04 现行 148 需预览复核）；底部信息卡底边距底 ≥ 300px（卡底 y ≤ 1620）；右侧 120px（x > 960）不放关键数据；左边缘 ≥ 56px。
- 渲染母版后用 FFmpeg 封装为 12Mbps MP4；实测视频码率不得低于 11.0Mbps。
- 详细工程结构、代码片段、渲染命令见 `references/remotion.md`。

## 6. 声音

- BGM 只用抖音热门音乐，不用 AI 生成；必须记录曲名、来源链接、抓取日期；旧工程遗留 BGM 未核验时不得声称“抖音热门”。
- BGM 混音增益约 **0.20**；口播清晰优先。
- BGM 首尾可做 0.3–0.8 秒淡入/淡出，避免硬起硬切；中途不做无意义 crossfade。
- 音效只在段落起点、数据卡、结尾等关键节点使用；约 **10 处/100 秒**，不逐镜添加。
- 音效优先免版税实录音效；UI/机械点击可用程序合成，但必须保留生成脚本与参数，不能拿合成音替代 whoosh/impact。
- 详见 `references/audio.md`。

## 7. 交付前自检（硬门槛）

**每次制作完成后必须完整跑一遍；未通过不得发 CDN，也不得覆盖本地成片。**

1. 技术检查：
   ```bash
   python3 "$SKILL_DIR/scripts/qc_video.py" <final.mp4> --expected-duration <秒> --json-out qc_report.json
   ```
2. 抽帧检查：关键段落首/中/尾帧、字幕切换帧、片尾卡；必须从**最终 mp4** 抽，而不是只看 Remotion still。
3. 安全区检查：
   ```bash
   python3 "$SKILL_DIR/scripts/safe_area_check.py" <final.mp4> --preset tp01 --times <秒,秒,...>
   ```
   检查标题、信息卡、数据、来源、片尾、封面都不被顶部/底部/右侧操作区遮挡。
4. 素材检查：语义对应、无黑帧/冻结/花屏/低清放大/拉伸/水印，产品抠图无白边、无裁切、不被卡片压住。
5. 字幕检查：底板常驻、切换不闪空、不双行叠加、不超底板、无错别字/孤字。
6. 封面检查：3:4（1080×1440），TP01 标题 top≥240、T04/TP02 标题 top≥120，主体与底部信息在安全区；**有底部信息卡的版本不能直接从 9:16 裁 0–1440**，要用无卡帧单独做封面。

逐项写“通过/不通过/原因/修改”到 `qc_report.json` 或 `qc_notes.md`。不通过就修、重渲染、再检。

## 8. 交付

- 先在对话里发 CDN mp4 预览；用户确认后才归档本地。
- 本地目录：`日期_脚本名/`；视频名=脚本名；生产期可用 `_v1/_v2/...` 区分过程版本；用户确认最终版后，只保留该最终 `_vN.mp4` 与最终封面，删除同项目所有过程版本和临时渲染。
- 参考过往视频时只读取最后版本（最高编号且已确认版），旧版不作为风格或素材依据。
- 封面命名：`脚本名_封面3x4_vN.jpg`；最终只保留与成片同版本的封面，过程封面删除。
- 需要飞书交付时按指定文档/单元格写入；单文件 >20MB 走 CDN/分卷/云盘通道；跨租户附件走表格素材上传通道。
- 交付说明写清：最终版本、时长、分辨率、帧率、实测码率、BGM 来源、自检结论。
- 详细流程与坑见 `references/delivery.md`、`references/pitfalls.md`。
